# 往栖缘叙 · 数字生命工坊

> **让离开的人，以另一种方式在场。**

导入聊天记录 → 情感分析 → AI 探讨 → 创建数字分身。一个本地运行的「数字生命」工作台：被拉黑了、亲人离世了、任何离开你的人，或者你只是想复刻一位说话方式——都可以用 TA 的聊天记录，生成一个语气高度相似的数字分身。

**数据 100% 本地处理，绝不上传任何服务器。纯本地、零风控、零遥测。**

## 🌟 功能

| 模块 | 说明 |
|------|------|
| 📥 记录收集 | 只做 JSON 收集。识别 QCE 导出 / 微信 WeFlow / 任意 `messages` 数组 / 带时间戳文本；**自动去重**（相同记录不重复导入）；**多平台整合**（同一联系人来自 QQ/微信，自动按时间合并去重） |
| 📊 情感分析 | 主动 / 被爱 / 冷淡三指数 + 全量统计（发起、回复速度、连轰、晚安、语言特征、活跃时段、消息类型）+ **6 种分析视角**：情感军师 / 老板分析 / 兄弟分析 / 同性恋分析 / 普通情感 / 深度思考 |
| 📈 数据可视化 | 折线图（每日趋势）、扇形图（消息类型占比）、条形图（活跃时段）、关系温度计仪表盘、时光线回顾 |
| 💬 AI 军师 | 右上角选择军师分类：真心军师 / 同性恋军师 / 老板军师 / 兄弟军师 / 深度军师，回答基于你的真实统计数据 |

| 💌 主动陪伴 | 设定时间点，数字分身主动在你界面里找你说话（纯软件内提醒，不会真的发给真实的人） |
| 🗣 心声树洞 | 把没说出口的话交给 TA 的数字分身听 |
| 📅 纪念日 | 记录值得记住的日子 |
| 🧩 技能管理 | 在设置页给数字分身添加自定义规则 / 能力（「每次心情不好先抱抱我」等） |
| 🎨 外观 | 自定义背景图上传、白色蒙版覆盖开关、我的头像上传 |

## 🚀 快速开始

**方式一：一键启动（推荐）**
1. 双击 `往栖缘叙.exe` —— 免装任何环境，自带运行时，自动打开桌面窗口（端口 10086）

**方式二：源码运行**
1. 安装 [Node.js 18+](https://nodejs.org/)(可选) 或 [Python 3.10+](https://www.python.org/)
2. `cd py && python app.py`（或双击 `start.bat`）

**使用流程**
1. 在「导入」页拖入导出的聊天 JSON
2. 「设置」页填入 API Key（DeepSeek 官方：地址 `https://api.deepseek.com`，模型 `deepseek-chat`）
3. 开始分析 / 探讨 / 创建数字分身

> 没有 API Key 也能用：统计功能、可视化完全本地；AI 深度分析与数字分身对话需要大模型 API。

## 📥 记录来源（只读，不碰任何客户端）

- **QQ**：用 [QQ Chat Exporter (QCE)](https://github.com/shuakami/qq-chat-exporter) 导出 JSON 后拖入
- **微信**：用 WeFlow 等工具导出 JSON 后拖入
- 任何含 `messages` 数组的 JSON、WeFlow JSON、带时间戳文本均可

本工具**只读取导出的 JSON 文件**，不访问客户端数据库、不模拟登录、不发送任何消息——对腾讯等平台的风控风险为零。

## ⚠️ 关于数字分身

- 数字分身是**说话风格的复刻**，不是真人：它只知道聊天记录里的事，超出部分会以 TA 的口吻「编造」，请保持清醒
- 适合：告别、思念、整理回忆、创作辅助；不适合：替代现实关系、逃避真实社交
- 若对话中出现自伤 / 轻生等安全信号，分身会严肃提醒并引导寻求现实帮助（这条优先于任何角色扮演）

## 🛠️ 开发

```bash
cd py
python app.py        # 启动源码版（端口 10086）
```

- **技术栈**：Python + pywebview 原生窗口 + PyInstaller 打包成独立 EXE（免装环境）
- 代码结构：
  - `py/app.py` — pywebview 窗口主程序（记住窗口位置、多屏支持）
  - `py/server.py` — 本地 HTTP 后端（端口 10086，全部 `/api/*` 端点）
  - `py/importer.py` — 格式识别与归一化（QCE / WeFlow / 通用 / Markdown）+ 去重 + 多平台整合
  - `py/stats.py` — 统计引擎（分数口径对齐 she-love-me）
  - `py/prompts.py` — 提示词工程（多视角分析、军师人格、数字分身、记忆、技能）
  - `py/llm.py` — OpenAI 兼容 API 客户端（Python 出网，稳定可靠）
  - `public/` — 前端界面（iOS 风格、SVG 图标、微信式布局、纯本地）
- `data/` 存放导入记录、设置、记忆、头像，已被 `.gitignore` 忽略，**切勿提交真实聊天数据**
